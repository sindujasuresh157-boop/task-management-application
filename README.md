# Task Management Application

A responsive web-based Task Management Application built using HTML, CSS, JavaScript, and Supabase.

## Features

- User authentication
- Create an account and login
- Add new tasks
- Edit tasks
- Delete tasks
- Change task status
- Set task priority
- Set due dates
- Search tasks
- Filter tasks by priority
- Dashboard with task counts
- Supabase database integration
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Supabase

## Project Purpose

This project helps users create, organize, track, and manage their tasks efficiently through a simple and responsive interface.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Start a local server.
4. Open the application in a web browser.
